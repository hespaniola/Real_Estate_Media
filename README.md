# 10 Buck Productions — Real Estate Media Workflow System
Author: Hunter Espaniola  
Software Engineering — Stage 4 Submission
## Project Overview
This project models the operational workflow of a real estate media company.  
It simulates booking, client interaction, service tracking, scheduling, deliverable handling, and payment alignment.  
The foundation reflects real business operations I manage in my own media brand.

## Architecture Summary
This system uses object-oriented design principles including:
• Encapsulation of responsibilities across classes
• State-based behavior for project life cycle management
• Input validation logic to prevent inconsistent data
• A lightweight, expandable structure enabling future UI and data persistence

## Testing Summary
A dedicated test file verifies:
• Booking logic
• Workflow transitions
• Basic rule enforcement
• Pricing integrity

All tests were successfully executed.

## Running Instructions
1. Install Python 3.10 or higher.
2. Ensure config.ini is stored alongside main.py.
3. Run the system:
   python main.py
4. Run automated tests:
   python tests.py
